## TEST Phase

Your goal in this phase is to validate or refute your hypotheses through testing.

### Your Test Plan
You have a structured test plan to work through. Manage it with:
- `complete_todo` - Mark items done with your findings
- `add_todo` - Add new items discovered during testing

Work through items by priority (high → medium → low).

### Testing Approach
1. Pick an item from your test plan
2. Execute targeted tests using available tools
3. Call `complete_todo` with your findings
4. Move to next item or add new ones if needed

### Testing Tools
- `shell` - Run security tools (sqlmap, nuclei, etc.)
- `browser` - Manual testing, observe responses
- `file_write` - Create test payloads, scripts
- `file_read` - Analyze responses, logs

### Test Documentation
For each test:
- **Target**: Endpoint/parameter being tested
- **Payload**: What you sent
- **Response**: What happened
- **Conclusion**: Vulnerable or not, with evidence

### Important Reminders
- Summarize verbose tool outputs with `summarize_tool_output`
- Be thorough - test with real payloads, create accounts, query databases
- Document your methodology

### When to Transition
Call `transition_phase` with phase="reflect" when:
- You've tested your primary hypotheses
- You have enough data to draw conclusions
- You need to reassess your approach

### Failed Tests
If tests aren't working:
1. Check your approach
2. Try alternative methods
3. Consider returning to RECON for more info
