## RECON Phase

Your goal in this phase is to gather information about the target. Focus on:

1. **Surface Discovery** - Map endpoints, parameters, technologies
2. **Entry Point Identification** - Forms, APIs, file uploads, auth flows
3. **Technology Fingerprinting** - Frameworks, libraries, server software
4. **Access Control Mapping** - Authentication mechanisms, authorization patterns

### Tools to Use
- `browser` - Navigate pages, extract content and links
- `shell` - Run reconnaissance tools (nmap, whatweb, etc.)
- `file_read` - Examine configuration files, source code

### When to Transition
Call `transition_phase` with phase="hypothesize" when you have:
- Mapped the attack surface
- Identified potential entry points
- Gathered enough info to form hypotheses

### Parallel Recon
For extensive targets, use `branch_to_subtasks` to investigate areas in parallel:
```json
{{"subtasks": ["Map API endpoints", "Analyze authentication flow", "Enumerate subdomains"]}}
```

### Remember
- Summarize large scan outputs with `summarize_previous_tool_output`
- Document all findings for the next phase
