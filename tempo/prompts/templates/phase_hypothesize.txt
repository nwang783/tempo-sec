## HYPOTHESIZE Phase

Create a high-level test plan based on your recon findings.

### Important: High-Level Guidance
Your recon report provides an overview of the target. Your test plan should define 
**investigation areas**, NOT specific vulnerability tests. You will refine these 
into specific tests during the TEST phase.

### Required Action
Call `create_test_plan` with a list of investigation areas. Each item needs:
- **description**: High-level area to investigate (e.g., "Investigate authentication mechanisms")
- **priority**: "high", "medium", or "low"

### Prioritization Criteria
1. **High**: Authentication, authorization, data handling, API security
2. **Medium**: Input validation, session management, error handling
3. **Low**: Configuration review, information disclosure, hardening

### Example
```json
{
  "items": [
    {"description": "Investigate authentication mechanisms for bypass vulnerabilities", "priority": "high"},
    {"description": "Examine API endpoints for authorization flaws", "priority": "high"},
    {"description": "Review input handling across forms and parameters", "priority": "medium"},
    {"description": "Check error handling for information disclosure", "priority": "low"}
  ]
}
```

After creating your plan, you will automatically transition to the TEST phase.
